# 0.0.1 build 36 preview

- Bundle the public-relay tunnel executable with the Windows app. Opening a TryCloudflare relay no longer requires a separate cloudflared installation or an administrator installation step.
- Prefer the bundled executable in the extracted single-file runtime. Existing external installations remain a fallback for older/custom runtime layouts.
- Download the pinned official component during the build, verify its SHA-256 digest and include its license. Refuse to package a desktop release missing either relay executable or the tunnel component's license.
- Preserve the build 35 message retry, durable-receipt and reconnection fixes.

Validation includes dependency resolution without a PATH installation, bounded/checksummed downloads, cache reuse, complete payload checks and a real public-tunnel startup using the bundled executable. The distributable remains one `chta.exe`. A network that cannot reach Cloudflare may still prevent that Desktop from hosting a tunnel; a working Direct or another community relay is then required.

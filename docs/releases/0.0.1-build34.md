# 0.0.1 build 34 preview

- Add a friend on one device. The other person can Review the signed name, fingerprint and optional alias, then Accept or Decline without scanning a card back.
- Keep outgoing requests and pending reviews in encrypted local storage. Retry while both apps are online. The discovery seed forwards live setup packets and has no offline request mailbox.
- Show Request pending and Waiting for approval separately from an established encrypted chat. Existing contacts have a Send request action; scanning a contact QR from chat also queues the request.
- Learn the signed relay routes supplied by an accepted peer. Preserve existing aliases and conversation history.
- Allow automatic connection setup with the default identity name when no profile name has been entered.

Both people need build 34 or newer for this Review flow. A successful friendship approval still needs a usable Direct or community-relay route for messages and files. The seed does not carry chat messages or files.

Verification includes native Rust identities and encrypted storage, pending-review restart, lost acceptance acknowledgement, a real encrypted chat handshake, browser WASM gateways, Worker WebSockets and regression tests. Only disposable synthetic accounts are used. The independent review service was unavailable; a separate author review and regression pass were performed instead.

# 0.0.1 build 32 preview

- Fix Android group rooms returning to the chat list. Group routes now pass both the UI and encrypted session-storage validators, including restoration after reopening the app.
- Keep authenticated group relay connections usable when WebRTC initialization or negotiation fails. Invitations and group messages can use the existing encrypted relay channel.
- Preserve the version-1 group wire format and existing identities, contacts and history. Group administrator/link extensions remain under development separately.

Validation includes regression tests for both route validators and failed Direct setup, plus an opt-in Windows test with two isolated native Rust identities, encrypted storage, a real local WebSocket relay, invitation acceptance and bidirectional group messages. No real user messages are sent by the test.

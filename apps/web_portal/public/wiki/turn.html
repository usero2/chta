TURN setup guide

TURN helps chta connect when your network blocks a direct connection. Use a private invitation from someone you trust or host your own server.

Add a TURN server to chta

  1. Open Connect → TURN fallback in chta.
  2. Paste the invite link or scan its QR code, then choose Save. Share the same invitation privately with the people you want to connect with.
  3. Open the conversation. New WebRTC connections try direct paths and can use TURN when needed. The chat header shows TURN when chta confirms that route.

Saving or removing a server applies to new connections. Restart chta if you need to replace an active connection right away.

Chats and files stay end-to-end encrypted. Your TURN operator can see network addresses and traffic volume. Files up to 25 MiB can use TURN. Larger files wait for a direct route.

Host your own TURN server

Use a Linux host with Docker Compose, a public IPv4 address, and a DNS A record such as turn.example.org. If your provider maps a public IP to a private interface, set both addresses below. Set the DNS record to DNS-only if you use a DNS proxy service.

  1. Allow inbound TCP 80 and 443 for HTTPS, TCP and UDP 3478 for TURN, and UDP 49160–49200 for relayed traffic. Use the same port numbers on both sides of any NAT.
  2. Download the server files on your host. 
    mkdir -p chta-turn
cd chta-turn
curl --fail --location --remote-name-all \
  https://chta.app/wiki/turn-server/compose.yaml \
  https://chta.app/wiki/turn-server/Caddyfile \
  https://chta.app/wiki/turn-server/issuer.mjs \
  https://chta.app/wiki/turn-server/turn.env.example
umask 077
cp turn.env.example .env
printf '\nTURN_ACCESS_TOKEN=%s\nTURN_SHARED_SECRET=%s\n' \
  "$(openssl rand -hex 32)" "$(openssl rand -hex 32)" >> .env
  3. Edit .env. Set TURN_HOST to your DNS name, TURN_PUBLIC_IP to the public IP, and TURN_LISTEN_IP to the IPv4 address on your Linux interface. Often both IPs are the same. Then start the server. 
    docker compose up -d
curl --fail https://turn.example.org/healthz
  4. Generate the link in a private terminal. Replace the example domain with your DNS name. 
    token=$(sed -n 's/^TURN_ACCESS_TOKEN=//p' .env)
printf 'https://turn.example.org/ice#%s\n' "$token"

    Send only the invite link to your contacts. To make a QR code locally, pipe the printf command above into qrencode -o turn-invite.png. Keep .env on your server.

Check the connection

A successful Save confirms that chta reached the credential service. To check TURN itself, try a chat from two separate networks where a direct path has previously failed. If the chat keeps reconnecting, check the TURN port and UDP port range in your cloud firewall and on the host.

coturn is open source. Your server and bandwidth can still cost money. The example sets connection and bandwidth limits that you can tune in compose.yaml.

To replace a shared invitation, generate a new TURN_ACCESS_TOKEN and run docker compose up -d. Existing temporary credentials can remain valid for up to an hour. Rotate TURN_SHARED_SECRET as well if you need to invalidate those credentials sooner.
